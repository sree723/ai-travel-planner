# 🌍 AI Travel Planner

An intelligent, full-stack AI-powered travel planning system that generates travel routes, itineraries, hotel suggestions, and budget breakdowns — with built-in memory, trust validation, and an interactive hidden gems map.

---

## 🚀 Features

### 🤖 AI Travel Engine
- Generates:
  - Best travel routes
  - Transport options
  - Hotel recommendations
  - Multi-day itinerary
  - Budget summary
- Uses Google Gemini AI

### 🧠 AI Memory System
- Stores past travel plans
- Displays travel history on homepage
- Simulates real-world AI system design

### 🔍 Trust Validation Layer
- Evaluates AI output
- Shows why a plan is reliable
- Adds transparency to AI-generated content

### 🗺️ Hidden Gems Map
- Interactive map using Leaflet.js
- Click-to-add secret places
- Upload photos
- Delete places
- Search and filter locations

### ✨ Demo Mode
- Works without API key
- One-click recruiter-friendly demo
- Shows full system behavior instantly
